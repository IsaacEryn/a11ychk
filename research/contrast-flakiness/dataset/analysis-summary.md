## [표 2] 대조군(base) 대비 위반 감소

각 제어를 켰을 때 base 대비 줄어든 요소 수. **감소분이 곧 오탐은 아니다** — 라벨링으로 확정할 것.

| 조건 | 위반 요소 합 | base 대비 증감 | 증감률 |

| base | 663 | 0 | — |
| rm | 697 | +34 | +5.1% |
| font | 677 | +14 | +2.1% |
| rm+font | 673 | +10 | +1.5% |

## 라벨링이 필요한 케이스 (양방향)
