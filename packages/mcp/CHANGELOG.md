# @a11ychk/mcp 변경 이력

npm 패키지 자체 버전을 따른다 (루트 CHANGELOG.md는 GitHub Action의 버전 축).

## 0.1.6

0.1.5에서 막지 못한 종료 경로 하나를 마저 고친 릴리스입니다.

URL 파서로 ada 3.x가 들어 있는 Node(24.0~24.19, 25.x, 26.0~26.6)에서, crawl_sample로 수집하는
사이트의 루트나 sitemap.xml이 `http://%EA%B0%80xn--.com/`처럼 특정한 모양의 국제화 도메인 주소로
리다이렉트하면 서버 프로세스가 통째로 종료될 수 있었습니다. 리다이렉트를 따라가는 fetch 내부에서
난 문제라 0.1.5의 링크 정리 수정으로는 막히지 않았습니다. 이제 리다이렉트를 직접 따라가며 그런
주소로 가는 리다이렉트는 따라가지 않습니다. 최대 횟수(20회)와 상대 경로·한글 주소 처리는 전과
같습니다. Node 22에는 원래 이 문제가 없습니다. 도구 이름·입력 형식·출력 구조 변경은 없습니다.

## 0.1.5

결함을 고치는 릴리스입니다.

도구 결과 말미 안내 링크의 검사 폼 미리 채우기가 0.1.3부터 도메인 주소에서 동작하지 않던
문제를 고쳤습니다. 사설망 판별이 도메인까지 사설 주소로 분류해서, example.com 같은 공개
사이트를 검사해도 링크에 주소가 실리지 않고 공개 IP로 직접 연 경우에만 실렸습니다. 이제 공개
도메인은 링크에 실리고, localhost·.local·.internal 같은 내부 이름과 사설 IP, file:// 경로는
전처럼 뺍니다. 주소에 넣은 사용자 이름과 비밀번호는 링크에 싣지 않습니다.

URL 파서로 ada 3.x가 들어 있는 Node(24.0~24.19, 25.x, 26.0~26.6)에서는 `http://가xn--.com/`처럼
특정한 모양의 국제화 도메인 주소 하나 때문에 서버 프로세스가 통째로 종료될 수 있었습니다.
crawl_sample이 수집한 링크를 정리할 때와 검사 결과 말미의 안내 링크를 만들 때 이 경로를 탔는데,
두 곳 모두 막았습니다. 해당 런타임에서는 이런 주소를 표본과 안내 링크에서 뺍니다. Node 22에는
원래 이 문제가 없습니다. 도구 이름·입력 형식·출력 구조 변경은 없습니다.

## 0.1.4

로컬 폴더를 서버 없이 검사하는 scan_dir 도구를 추가했습니다. 디렉터리에서 HTML 파일을 재귀로
모아 file://로 일괄 검사하며, 결과 형태는 scan_pages와 같습니다. scan_page도 file:// URL을
공식 지원하고, 없는 파일이나 디렉터리는 브라우저를 띄우기 전에 걸러 안내합니다. file://에서는
fetch가 막혀 CSR SPA 산출물이 빈 페이지로 뜨므로, 그런 경우에는 dev 서버 주소로 검사하세요.

원본 소스 기반 마크업 유효성 검사가 들어갔습니다. 렌더링 전 응답 본문을 다시 파싱해 닫는 태그
누락, 잘못된 중첩, 속성 중복과 문서 전체의 id 중복을 KWCAG 8.1.1(WCAG 4.1.1) 위반으로
보고합니다. 그래서 같은 페이지에서도 이전에 없던 위반이 새로 나올 수 있습니다. 파서가 조용히
복구하는 중첩(p 안의 div 등)은 잡지 못합니다.

## 0.1.3

검사 결과의 판정 정확도를 고치는 릴리스입니다.

규칙 카탈로그에 없는 axe 규칙의 위반이 '모범 사례 권고'로 잘못 분류되면서, 해당
성공기준이 위반 없는 것으로 보고되던 문제를 고쳤습니다. 같은 기준의 다른 규칙이
통과하면 실제 위반이 있는 기준이 통과로 찍히기까지 했습니다. 이제 규칙이 카탈로그에
없어도 axe 태그에서 대응 성공기준을 복원해 적합성 위반으로 셉니다. 실제로 이 구멍에
빠져 있던 aria-tab-name과 랜드마크 규칙 네 개는 한국어 가이드와 함께 카탈로그에
넣었습니다(총 111개).

건너뛰기 링크(2.4.1) 검사가 페이지 안의 아무 앵커나 통과로 인정하던 것도 고쳤습니다.
목차 링크만 있는 페이지가 통과로 찍히지 않도록, 대상이 본문 영역인 앵커만 인정합니다.

그밖에 서버가 자기 버전을 0.1.0으로 보고하던 것을 바로잡았고, Node 요구 버전을 실제
의존성에 맞춰 22.19 이상으로 정정했습니다(이전 표기는 20 이상이라 Node 20에서 설치가
경고만 내고 지나간 뒤 런타임에서 깨질 수 있었습니다). Apache-2.0 전문도 패키지에
포함했습니다. 도구 이름·입력 형식·출력 구조 변경은 없습니다.

## 0.1.2

도구 결과 말미의 서비스 안내가 실제 링크가 됐습니다. 공개 URL을 검사한 경우에는
a11ychk.com 검사 폼에 그 주소가 미리 채워지는 딥링크를 안내합니다(localhost 등
비공개 주소는 제외). 검사·판정 동작 변경은 없습니다.

## 0.1.1

공식 MCP 레지스트리(registry.modelcontextprotocol.io) 등재를 위한 릴리스입니다.
레지스트리가 npm 패키지 소유를 확인할 때 참조하는 `mcpName` 필드(`com.a11ychk/mcp`)를
package.json에 추가하고, 레지스트리 메타데이터인 server.json을 함께 둡니다.
서버 동작 변경은 없습니다.

## 0.1.0

첫 릴리스. AI 코딩 도구(Claude Code·Cursor 등)에서 웹 접근성 검사를 직접 호출하는
MCP 서버입니다. a11ychk.com과 같은 엔진(axe-core + 자체 규칙)으로 검사하고, 모든
위반을 WCAG 2.2 성공기준과 KWCAG 2.2 검사항목에 함께 매핑하며, 위반마다 한국어
개선 가이드를 돌려줍니다. localhost 개발 서버 검사에 적합합니다.

도구 다섯 개 — `scan_page` / `scan_pages`(chromium 필요), `crawl_sample`,
`get_fix_guide`, `kwcag_checkpoint`(브라우저 불필요).

브라우저는 첫 검사 때 확보합니다. playwright 관리 chromium이 없으면 설치된
Chrome으로 폴백하고, 그것도 없으면 설치 명령을 안내합니다.
